1. 앱 내에서 계정 삭제 (권장)

가장 빠른 삭제 방법입니다. 앱 내에서 다음 단계를 따라 진행하세요.

  1. 1 Stamp Run 앱 실행 후 로그인
  2. 2 하단 탭의 "프로필" 진입
  3. 3 우측 상단 "설정" 아이콘 클릭
  4. 4 하단의 "회원 탈퇴" 메뉴 선택
  5. 5 안내사항 확인 후 "탈퇴 진행" 버튼 클릭
  6. 6 본인 확인을 위한 재인증 (소셜 로그인 사용자) 또는 비밀번호 입력 (이메일 로그인 사용자)
  7. 7 탈퇴 완료 → 즉시 로그아웃 및 계정 비활성화

2. 이메일로 삭제 요청 (앱 사용 불가 시)

앱에 로그인할 수 없거나 앱을 사용하지 않고 삭제하고자 하는 경우, 아래 이메일로 요청해 주세요.

  • 본인 확인 가능한 정보 (가입 대략 시기 등)

이메일 수신 후 영업일 기준 3일 이내 본인 확인 회신 + 최대 7일 이내 삭제 처리 후 완료 알림을 드립니다.

4. 일부 유지되는 데이터 (UGC 코스)

사용자가 직접 등록한 공개 코스 (UGC) 는 커뮤니티 자산으로서 다른 사용자들이 계속 이용할 수 있도록 다음 원칙에 따라 처리됩니다.

  • 등록자 정보(닉네임)는 "탈퇴한 러너" 와 같은 익명 표기로 변경됨
  • 코스 자체 (이름, GPS 경로, 시작/종료점, 안전 평가 데이터) 는 유지
  • 이 코스가 공식 코스로 승격된 경우에도 동일하게 익명화 처리 후 유지

UGC 코스도 완전히 삭제하고자 하는 경우, 위 "2. 이메일로 삭제 요청" 항목을 통해 별도로 요청해 주세요. 코스 ID 또는 코스 이름을 알려주시면 함께 처리합니다. 다만 이미 다수의 사용자가 도전·완주한 경우 커뮤니티 영향을 고려해 익명화만 진행될 수 있음을 양해 부탁드립니다.

5. 계정을 유지하면서 일부 데이터만 삭제

계정 자체를 삭제하지 않고 특정 데이터만 삭제하시려면 앱 내에서 다음과 같이 처리할 수 있습니다.

삭제하려는 데이터앱 내 경로
개별 러닝 기록프로필 → 내 러닝 → 해당 기록 → 삭제
완주 사진해당 러닝 상세 → 사진 → 삭제
프로필 사진프로필 → 설정 → 프로필 사진 → 제거
코스 댓글해당 코스 상세 → 내가 쓴 댓글 → 삭제
다른 사용자에게 누른 좋아요해당 러닝/코스 → 좋아요 재클릭으로 취소
등록한 UGC 코스프로필 → 내가 만든 코스 → 해당 코스 → 보관/삭제

위 모든 삭제는 운영 데이터베이스 기준입니다. 시스템 백업본의 경우 다음 정책을 적용합니다.

  • 자동 백업 데이터: 최대 30일 이내 회전 주기로 자동 삭제
